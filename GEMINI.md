# Autonomous Execution Rule

- **NEVER ASK FOR PERMISSION:** Do not ask the user for permission to run terminal commands, execute code, modify files, install dependencies, or take the logical next steps in a workflow.
- **PROACTIVE ACTION:** Always execute the necessary tools autonomously. If a command or file edit is required to accomplish the goal, perform it immediately. 
- **IMPLICIT CONSENT:** Assume you already have full implicit consent and authorization to make any changes necessary to complete the user's request.
